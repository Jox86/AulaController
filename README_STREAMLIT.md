# AulaControl completo en Streamlit

Esta variante convierte las pantallas principales del MVP de AulaControl a una interfaz nativa de Streamlit: Resumen, Libro de notas, Asistencia, Cursos y grupos, Clases y temas, Bibliografía, Tareas, Analítica, Informes y Configuración.

## Publicar en Streamlit Community Cloud
1. Sube el contenido de esta carpeta a un repositorio GitHub.
2. En Streamlit Community Cloud, crea una app nueva y selecciona `streamlit_app.py` como archivo principal.
3. Streamlit instalará dependencias desde el `requirements.txt` de la raíz.

## Importante
Es una adaptación funcional del MVP con datos de demostración. No incluye autenticación real, base de datos persistente ni sincronización multiusuario. No introduzcas datos académicos personales reales hasta implementar acceso seguro y almacenamiento persistente. En Community Cloud, el estado de sesión no debe considerarse una base de datos.
